# CNPS.AI 图片、动效与三语博客发布记录

日期：2026-09-05

## 目标与设计

从海外 B2B 买家的三项工作出发：理解设备、评估业务适配、提出可回复的询盘。延续深蓝、青色与银白品牌视觉，把原有抽象球体与真实产品图片结合；增加三组可操作的应用流程、图文参考卡片及完整博客阅读体验。

- 首页：INMO GO3 与 TicNote 产品展示、知识/会议/边缘 AI 流程切换、博客推荐。
- 图像：三张原创 AI 概念配图，六个响应式 WebP 总计约 230 KB；保留并标识原有商品图片，概念图不作为客户交付或准确 SKU 的证据。原图归档不进入站点构建。
- 动效：滚动渐显、错峰入场、桌面轻微视差与倾斜、语音与流程状态提示。离屏和后台停止持续动效；全局暂停和系统减少动态设置优先。
- 博客：6 篇原创文章 × 中文/英文/阿拉伯语，共 18 篇正文；每篇六节、约 680 英文词及完整译文。分类搜索、目录、阅读进度、复制链接、打印、相关文章、询盘入口和三语 RSS。
- 导航：`/blogs` 与其文章路径永久跳转到对应英文版本；三语博客在导航、页脚、首页、站点地图中可达。切换语言保留当前流程或阅读章节。
- 可访问性：键盘流程标签、阿语 RTL、无 JavaScript 的完整内容与移动导航；不以隐藏正文作为动画默认状态。

## 内容与维护位置

- `content/i18n/blogs.json`：三语文章与元数据单一来源。
- `scripts/editorial-components.mjs`：共享图片、应用流程、图文卡片与首页博客区。
- `web/experience.mjs` 与 `web/assets/experience.css`：交互与视觉。
- `web/motion.mjs` 与 `web/assets/motion.css`：独立渐进增强动效控制。
- `docs/strategy/blog-editorial-notes.md`：编辑规则与译文一致性。
- `docs/strategy/editorial-image-provenance.md`：生成方式、实际提示词与图片尺寸。

新增文章时必须同时提供三种语言的完整正文、标题、摘要和图片说明；构建遇到缺少译文或重复 slug 会失败。文章日期为实际发布日，后续改稿应同步维护日期与阅读时间。

## 验证

- 严格构建：228 个语言页面（每语 75 个内容页 + 1 个 404），无翻译回退。
- 原有 HubSpot 测试：19 项通过。
- 响应式浏览器：90 组语言、页面与宽度组合通过，无横向溢出、导航重叠或首屏图片错误。
- 博客、搜索、语言切换、阅读、归因、移动导航与无 JavaScript：56 项检查通过，零 JS 错误，零真实询盘提交。
- 全站静态检查：14,339 个本地引用、1,368 个语言切换链接及元数据通过；零断链、锚点错误或跨语言错误。
- 独立复核：手动暂停跨刷新/系统偏好变化保持有效，首页图片不被暂停状态隐藏；标签与阅读位置可跨语保留。
- 初次浏览器验收的阅读进度等待和中文最小长度条件不适配实际行为，调整为等待平滑滚动产生进度、按语言验证正文长度后通过；页面正文没有因此缩减。

证据：`journal-browser-qa.json`、`journal-link-audit.json`；发布阶段的真实 HTTP 结果将在完成后记录。
