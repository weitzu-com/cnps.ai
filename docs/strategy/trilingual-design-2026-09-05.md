# CNPS.AI 三语言体验设计

## 第一性原理

海外B2B采购需要理解任务、核验证据、确定责任、联系可信供应方。每页围绕其中一个下一步展开。“敬天AI人”表达对事实和规律的敬畏、以AI服务人的价值观；不把它写成未经验证的技术或商业承诺。

## 视觉选择

- 深空蓝 #081B29：首页、导航与重点展区。
- 星海蓝 #14374D：层次与轨道细节。
- 电光青 #6CE5DF：动作和信号。
- 银白 #F3F7F8：长文、表单与资料阅读。
- 墨蓝 #132E3D：浅色背景正文。
- 石板灰 #56707E：次级信息。

标题使用 Space Grotesk；正文使用 Manrope；中文使用系统黑体，阿拉伯语使用 Noto Sans Arabic。下载可公开分发的字体并保留许可证，减少外部字体请求。排版使用逻辑方向属性，阿语排版独立检查，邮箱、型号、URL保留LTR隔离。

首页以大字与可交互的智能轨道球面为视觉签名，模拟从设备到知识和业务任务的连接。其余页面减少动效与装饰，突出内容和动作。可减少动态的系统偏好将停用环境动画。

## 布局比较与选择

放弃每段都用三张相同卡片的方案；首页采用不对称产品展区、场景选择与横向步骤。目录页面用可搜索筛选的统一条目，详情页面用宽正文与短行动侧栏，研究报告用章节导航与阅读工具。

首页：导航 → 标题/轨道球面 → 三类买方入口 → 产品与应用 → 证据 → 工作流程 → 敬天AI人 → 询盘。
详情：路径 → 明确任务 → 范围/证据/边界 → 下一步。
报告：摘要/语言/下载 → 章节目录 → 完整正文。

## 语言与连续性

/en、/zh、/ar 对应完整语言路由。导航、正文、表单和状态提示按语言编译；语言切换保持当前路径、有效查询参数和章节锚点。使用 lang、dir、canonical、hreflang、x-default 与多语言sitemap。既有网址重定向到对应版本，既有下载保留。

旧产品与政策正文迁入统一页面，不再依赖旧部署的HTML；原始资料与修订证据保留，历史版本可明确标注源语言。外部商店保持独立链接。

## 询盘

保留现有HubSpot公开表单配置、真实成功确认、失败后邮件草稿、未经预选的处理同意、无营销订阅、来源标识。访问页面不创建线索；测试拦截POST，不发送测试客户资料。

## 验证

检查三语言路径覆盖、缺失翻译、页面与下载链接、同页语言切换、阿语方向、375/414/768/1024/1440视口、键盘菜单、减少动态和询盘成功/失败分支。保留正式版本回滚地址，核验候选部署后发布。
