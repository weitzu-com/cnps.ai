# CNPS 资料中心设计与部署决策

对象是负责选型、技术验证和采购的海外企业买家；页面的主要工作是把一个采购问题连接到证据、评估清单和询价。

采用 frontend-design 技能：主色海军蓝 #122B49，行动色工程蓝 #245BCB，浅蓝底 #EAF2FC，正文 #263A50，白色 #FFFFFF，证据状态绿色 #17684B。标题用 Avenir Next / Arial 的宽体无衬线，正文用系统无衬线，编号和标签用 SFMono / monospace。字体采用本地回退，不依赖外部字体请求。

首轮构想是常见三卡片英雄区；审阅后改成采购工作台：左侧是一条直接的价值陈述，右侧是按真实买家问题组织的纵向选型路径。标志元素为用途、证据、试点、报价四个相连的步骤。目录的结构承担解释作用，不用虚构销量、伙伴 Logo 或装饰性数据。

首页：导航 → 两列采购入口 → 三个主方向 → 证据案例 → 下载资料 → 询价。
资料页：标题与用途 → 筛选 → 带格式和适用角色的资源清单 → 对应询盘。
案例页：证据类别 → 业务问题 → 已知事实 → 限制 → 买方验收 → 来源。

移动端单列，导航可换行，触控不小于 44 像素；页面使用静态 HTML、少量原生 JavaScript 和可下载 Markdown。没有收集客户数据的后台，询价明确打开邮件草稿并要求用户发送。

旧站源码不在当前 GitHub 且 Vercel 文件树不可获取。保留已核实可公开访问的不可变旧部署作为产品与政策路径的上游，只为新主页、资料、案例、方案和询盘构建静态内容。不得删除旧部署；完整源码找回后可独立迁移这些旧路径。原生产部署可用于回滚，ID dpl_DDnaWFVdpc1xaUNwVmsE9G6hg9QZ。
