# 中国企业客户档案

客户档案入口位于客户工作台导航，仅高级管理员及当前公司销售经理可读取、维护。客户身份、项目授权继续由 Twenty 原生公司/联系人与现有授权目录决定；税号、银行账号、收件地址不会用于自动授权。

## 信息结构

- 企业：法定全称、统一社会信用代码、注册地址、企业电话、网站。现有 CRM 显示名称可能是简称，不自动当作法定全称。
- 开票：数电普票/专票、纸质普票/专票、抬头、税号、开票地址电话、开户银行及支行、银行账号、发票接收邮箱。数电类型不强制银行资料；纸质专票缺少地址电话与银行资料时列入待办。允许先建草稿、逐步补齐。
- 收件：最多20个地址，每个地址含名称、收件人、电话、省市区、详细地址、邮编，且只设一个默认地址。注册地址、开票地址、收件地址分别维护。

## 自动化

粘贴按行标注的客户资料，例如 `企业名称：`、`税号：`、`开户行：`、`银行账号：`、`发票邮箱：`、`收件人：`、`收件电话：`、`收件地址：`。服务端确定性提取；重复冲突不选值，未识别行不写入。确认表单保留原有字段，经理逐项复核后才保存。原始粘贴文本不保存、不交给外部 AI。

开票编辑可使用企业全称和信用代码作为抬头、税号草稿。全角字符、首尾空格、电话与账号分隔符自动规范；账号保留前导零。统一信用代码只做18位字符格式检查，不宣称已完成官方真实性或校验位核验；纳税人识别号兼容15至20位字母数字。未填写、纸质专票缺项自动生成待办。

## 存储与验证

扩展公司隔离业务存储，不更改原生公司与联系人字段。保存校验档案版本；多人修改时返回409，不覆盖他人更新。沿用目录和公司 CAS 校验，授权被撤销时提交失败。每次保存保留完整版本快照与修改人时间；公共操作记录只记版本，不记录税号、银行账号或完整收件信息。

本功能维护开票资料，不直接开具、发送发票，也不提交快递订单。新字段不从历史截图或不明来源自动回填。

依据：国家税务总局2017年第16号公告规定企业普通发票需提供纳税人识别号/统一社会信用代码；辽宁省税务局数电票答疑说明数电发票票面购销方信息显示名称、税号。资料完整性提示不等于发票有效性结论。
