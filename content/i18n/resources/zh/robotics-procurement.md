# 机器人采购：配置与 SDK 权限

适用于研究实验室与集成团队。机器人本体、开发平台和完整工作站可能涉及不同配置与责任。

## 确认确切配置

- 产品、版本、序列号或配置代码及固件。
- 针对该版本的开发权限书面确认。
- SDK 版本、操作系统、接口与受支持示例。
- 负载、工作半径、工作空间、末端执行器、工装及摄像头。
- 电池、充电、运输包装与备件。
- 目的地供货、培训、保修和服务安排。

[Unitree SDK2](https://github.com/unitreerobotics/unitree_sdk2) 与 [UFACTORY xArm Python SDK](https://github.com/xArm-Developer/xArm-Python-SDK) 是公开技术参考。公开仓库不能证明每个型号都具有相同权限，也不能证明与 CNPS 存在商业关系。

## 定义实验

明确任务、代表性物体、允许动作与人员参与方式。指定合格操作人员与现场安全负责人。尽可能从仿真开始，再开展受控、有人监督的测试。

以全部尝试次数为分母统计成功次数。保留失败运行、恢复时间及配置变更。简短成功视频无法显示失败率或操作人员协助程度。

## 报价前分配责任

| 责任 | 需要指定的负责人 |
|---|---|
| 硬件供应及确切版本 | 供应商 |
| 集成与工装 | 集成商或客户工程团队 |
| 现场安全与允许的操作 | 合格现场负责人 |
| 培训、维护和备件 | 约定的服务商 |
| 验收与变更请求 | 客户项目负责人 |

## 准备需求

提供目的地、研究或工业任务、倾向平台、开发要求、数量、时间安排与本地支持计划。CNPS 可讨论采购需求；具体供货与支持范围必须确认。
