# 规划 AI 会议设备试点

适用于评估录音设备的团队管理者与经销商。产品规格、订阅条款和供货情况必须按确切商品及目的地确认。

## 选择有代表性的试用

选择能够代表预期用户的小组。纳入真实会议语言、发言人口音、会议室大小和远程通话安排。使用已授权录音，并按场景提供适当告知、取得同意。

试用前测量记录、修正和分发纪要所需的时间。试用中测量包含修正在内的完整流程。单纯转写更快，并不能证明产生了实用的节省。

## 记录结果

| 字段 | 记录内容 |
|---|---|
| 设备与套餐 | 确切型号、固件、账号及包含的订阅 |
| 测试条件 | 语言、发言人数、距离及噪声 |
| 输出质量 | 遗漏陈述、姓名错误与行动项错误 |
| 审核投入 | 形成可用纪要所需分钟数 |
| 采用情况 | 各预期用户完成的使用次数 |
| 数据流程 | 导出格式、存储、分享与删除 |
| 恢复 | 断网或账号变更后的行为 |

请勿将敏感会议内容放入公开反馈表，评估数据应保存在获批准的企业系统中。

## 检查团队归属

询问账号与订阅是否可转移、是否具有团队管理功能，以及员工离职后由谁控制录音。不能根据消费级功能推定这些能力。

经销订单还需明确包装、目的地兼容性、保修处理、更换流程、文档及所需渠道授权。承诺大批量采购前，应取得书面条款。
